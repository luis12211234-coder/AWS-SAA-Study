# ☁️ AWS SAA Study

AWS Certified Solutions Architect – Associate(SAA-C03)를 준비하며 작성하는 한·일·영 학습 저장소입니다.

## 📌 About This Repository

강의를 단순히 받아 적는 대신, AWS 서비스를 **언제 선택하는지**, **비슷한 서비스와 무엇이 다른지**, **시험에서 어떤 표현으로 등장하는지**를 중심으로 정리합니다.

- 🇰🇷 한국어: 개념을 정확히 이해하기 위한 본문
- 🇯🇵 日本語: 일본 IT 환경에서 설명하기 위한 요약
- 🇺🇸 English: AWS 공식 용어와 기술 영어 복습
- 🎯 Exam Notes: SAA-C03 선택 기준과 함정
- 📝 Review Questions: 스스로 설명할 수 있는지 확인
