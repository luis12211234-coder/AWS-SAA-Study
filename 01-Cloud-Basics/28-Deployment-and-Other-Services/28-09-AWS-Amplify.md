# 📘 28-09. AWS Amplify

> [!NOTE]
> **AWS SAA-C03 Study Note** · GitHub Section 28 · Udemy Section 30  
> **Keywords:** Frontend, Backend

## 🇰🇷 1. 핵심 개념

Amplify는 웹·모바일 앱 개발과 배포, 프런트엔드 및 백엔드 연결을 간소화한다.

## 🇰🇷 2. 동작 원리 및 사용 사례

인증·데이터·스토리지·API 등 앱에 필요한 백엔드 기능과 프런트엔드 라이브러리를 연결한다. Amplify Hosting은 Git 저장소 연동 CI/CD와 웹 호스팅을 지원한다. Cognito·AppSync·Lambda 등 필요한 AWS 서비스를 활용할 수 있다. Elastic Beanstalk와는 대상 및 기능이 다르지만 개발 편의성이라는 공통점이 있다.

## 🇰🇷 3. 서비스 선택 기준

웹·모바일 앱의 풀스택 개발 및 배포 → Amplify. SaaS 데이터 파이프라인은 AppFlow.
