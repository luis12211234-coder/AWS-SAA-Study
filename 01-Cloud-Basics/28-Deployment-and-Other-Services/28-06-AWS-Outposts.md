# 📘 28-06. AWS Outposts

> [!NOTE]
> **AWS SAA-C03 Study Note** · GitHub Section 28 · Udemy Section 30  
> **Keywords:** On-Premises, Hybrid Cloud

## 🇰🇷 1. 핵심 개념

Outposts는 AWS 인프라와 일부 AWS 서비스를 기업 온프레미스 시설로 확장한다.

## 🇰🇷 2. 동작 원리 및 사용 사례

AWS가 Outposts 하드웨어를 설치·관리하고 기업은 기존 AWS 도구로 EC2·EBS 등 지원 리소스를 온프레미스에서 운영한다. 로컬 처리, 낮은 지연, 데이터 위치 요건에 적합하다. 모든 AWS 서비스가 지원되는 것은 아니며 Region 연결과 물리적 보안 책임을 고려해야 한다.

## 🇰🇷 3. 서비스 선택 기준

자체 데이터센터 내부에 AWS 인프라가 필요하면 Outposts. 일반 AWS Region의 리소스와 위치를 혼동하지 않는다.
