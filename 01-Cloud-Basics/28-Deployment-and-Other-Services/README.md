# 📚 28. Deployment and Other Services

> [!NOTE]
> **AWS SAA-C03 Section Guide** · `GitHub Section 28` · `Udemy Section 30`

## 📌 Overview

CloudFormation, Systems Manager, 비용 관리, 하이브리드 클라우드, 배치 처리, SaaS 데이터 통합 및 웹·모바일 앱 개발 서비스를 다룬다. 핵심은 **상황별 AWS 서비스 선택 기준**이다.

## 🎯 Learning Objectives

1. CloudFormation과 Service Role의 관계를 이해한다.
2. SES와 Pinpoint의 역할 및 서비스 변경 사항을 구분한다.
3. Systems Manager의 접속·명령·패치·일정·자동화 기능을 구분한다.
4. 비용 분석, 이상 탐지, 인스턴스 일정 관리를 비교한다.
5. Outposts, Batch, AppFlow, Amplify의 대표 사용 사례를 설명한다.
