> 한국어로 이해하고, 일본어와 영어로 다시 설명하는 학습 기록

## 📌 Overview

이 디렉터리는 AWS SAA 강의에서 학습한 개념을 서비스·아키텍처 주제별로 정리한다. 각 노트는 시험 암기만이 아니라 **선택 기준, 실무 맥락, 유사 서비스 비교**를 함께 남긴다.

## 🧭 Documentation Standard

각 학습 노트는 다음 순서를 따른다.

1. 제목과 핵심 키워드
2. 🇰🇷 한국어 핵심 개념
3. 🎯 Exam Notes
4. 📝 Review Questions
5. 🇯🇵 日本語 Summary
6. 🇺🇸 English Summary
7. 📚 Vocabulary
각 문서의 복습 문제는 정확히 5개이며, 답과 해설은 접기 영역 안에 배치한다.

## 🎯 Study Principles

- 강의 대본을 그대로 옮기지 않고 핵심 개념과 선택 기준을 재구성한다.
- 시험 키워드는 실제 요구사항과 연결해 이해한다.
- 한국어로 이해한 뒤 일본어와 영어로 요약한다.
- 액세스 키, 비밀번호 등 민감한 자격 증명은 저장소에 올리지 않는다.
